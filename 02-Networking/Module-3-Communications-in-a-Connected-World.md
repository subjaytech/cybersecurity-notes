## Wireless Communication Technologies

Modern smartphones contain several wireless communication technologies, each designed for a specific purpose.

### Cellular Networks (4G/5G)

Cellular networks provide voice and data services through mobile network operators.

Common uses include:

- Phone calls
- SMS
- Mobile Internet

---

### Wi-Fi

Wi-Fi connects devices to local wireless networks for Internet access.

Advantages include:

- Higher speeds
- Reduced mobile data usage
- Local network connectivity

---

### Bluetooth

Bluetooth enables short-range, low-power communication between nearby devices.

Common applications include:

- Wireless headphones
- Smart watches
- Vehicle infotainment systems
- Wireless keyboards and mice

---

### Near Field Communication (NFC)

NFC supports communication between devices over very short distances.

Typical uses include:

- Contactless payments
- Digital access cards
- Device pairing

---

### GPS

Global Positioning System (GPS) determines a device's geographical location using satellite signals.

Common uses include:

- Navigation
- Maps
- Location-based services
- Fitness tracking

---

## Simultaneous Wireless Communication

One key concept from this module is that a smartphone can use several wireless technologies at the same time.

For example, a user may:

- Browse the Internet using Wi-Fi.
- Listen to music through Bluetooth headphones.
- Receive text messages over the cellular network.
- Access location services through GPS.

Each technology performs a different function without interfering with the others.

---

## Wireless Security

The module emphasised the importance of securing wireless communications.

Recommended practices include:

- Use WPA2 or WPA3 encryption for Wi-Fi networks.
- Avoid transmitting sensitive information over unsecured public Wi-Fi.
- Use a VPN when accessing sensitive services on public networks.
- Keep device software updated.
- Disable wireless services when not in use.

---

## Bluetooth Pairing

Bluetooth communication typically follows these steps:

1. One device is placed in discoverable mode.
2. Another device scans for nearby Bluetooth devices.
3. The user selects the correct device.
4. Pairing is confirmed, often using a PIN or verification code.
5. A trusted wireless connection is established.
