# Networking Basics - Modules 1 & 2: Networking and Communications

## Overview

These modules introduced the fundamental concepts of networking, including how devices communicate, the components that make up a network, transmission media, and the different roles of network devices.

Although many of the concepts were familiar from my undergraduate Data Communication and Networking course (CSC 402), this course reinforced those foundations while presenting some topics from a different perspective.

---

## Learning Objectives

By completing these modules, I was able to:

- Explain how devices communicate over a network.
- Differentiate between clients and servers.
- Identify end devices, intermediate devices, and network media.
- Describe how Internet Service Providers (ISPs) connect users to the Internet.
- Understand how data is transmitted across different media.
- Distinguish between bandwidth and throughput.

---

## Client and Server Model

A client is a device or application that requests services or resources.

A server provides services or resources to clients.

In a peer-to-peer (P2P) network, a single device can function as both a client and a server depending on the task being performed.

---

## Network Components

### End Devices

End devices are the devices users interact with directly.

Examples include:

- Desktop computers
- Laptops
- Smartphones
- Tablets
- Printers
- Servers

---

### Intermediate Devices

Intermediate devices forward, manage, and secure network traffic.

Examples include:

- Routers
- Switches
- Wireless Access Points
- Firewalls

---

### Network Media

Network media provides the communication path between devices.

Examples include:

- Copper Ethernet cables
- Fibre optic cables
- Wireless communication

---

## Internet Service Providers (ISPs)

Internet Service Providers connect homes and businesses to the Internet using different technologies, including:

- Cable
- DSL
- Fibre
- Cellular
- Satellite

---

## Data Transmission

Digital information is represented as binary data (bits).

Depending on the transmission medium, those bits are converted into:

- Electrical signals
- Optical signals
- Radio waves

before being transmitted across the network.

---

## Bandwidth vs Throughput

### Bandwidth

Bandwidth represents the maximum theoretical amount of data that can be transmitted over a network connection.

### Throughput

Throughput represents the actual amount of data successfully transmitted under real-world conditions.

Factors that reduce throughput include:

- Network congestion
- Latency
- Packet loss
- Hardware limitations

---

## Reflection

One concept I found interesting was the way Cisco categorised transmission media into:

- Electrical
- Optical
- Wireless

During my undergraduate networking course, transmission media was introduced differently:

- Guided Media
- Unguided Media

Guided media included physical transmission media such as copper and fibre optic cables, while unguided media referred to wireless communication.

Although the classifications differ, both describe the same underlying networking concepts from different perspectives.

This reinforced an important lesson: different learning resources often organise concepts differently without changing the underlying principles.
